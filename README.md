# 📝 Blog Management Website

A modern, responsive Blog Management Website built using **HTML, CSS, and JavaScript**. It provides a clean dashboard to manage blog posts with an attractive user interface and interactive features.

## ✨ Features

- 📊 **Dashboard:** View blog statistics and post information.
- ➕ **Create Posts:** Add new blog posts with titles, content, and categories.
- ✏️ **Edit Posts:** Update existing blog posts.
- 🗑️ **Delete Posts:** Remove unwanted posts.
- 🔍 **Search Posts:** Find posts quickly using the search feature.
- 🏷️ **Filter Posts:** Filter posts by category and status.
- 📝 **Draft Management:** Save posts as drafts before publishing.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 💾 **Local Storage:** Save posts in the browser using localStorage.
- 📱 **Responsive Design:** Works on desktop, tablet, and mobile screens.
